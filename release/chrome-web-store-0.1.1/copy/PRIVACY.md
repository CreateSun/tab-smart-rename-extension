# Tab Rename 隐私说明

Tab Rename 的重命名功能不发送页面标题、URL、规则或用户设置。扩展不采集遥测，不包含广告或远程代码。

永久规则和暂停站点保存在浏览器本地存储中；当前标签命名保存在浏览器会话存储中；仅当前页面命名保存在页面内容脚本内存中。导出文件只包含用户创建的永久规则。

可选的网站访问权限仅用于在用户授权的网站上读取并修改标签页标题、在导航后自动应用规则。用户可随时从浏览器扩展设置中撤销权限。

卸载扩展后，浏览器可能打开一个由 Tally 托管的可选反馈页。该页面的 URL 不包含标签名称、访问网址或规则；用户可直接关闭页面，也可自行决定是否向 Tally 提交反馈。第三方页面的数据处理受其自身隐私条款约束。
