新建重命名规则

正则规则可使用捕获组；名称中的 $1 会替换为第一个捕获值。{1} 是单个路径段捕获的快捷写法。

RULE GUIDE

选择适合的规则

规则命中时，标签会自动使用“新标签名称”。选择最小匹配范围，结果会更可预测。

精确 URL

只匹配一个完整网址，适合固定页面。

规则
https://notion.so/acme/weekly-review
实际 URL
https://notion.so/acme/weekly-review
title 效果
本周复盘

域名

匹配该域名下所有页面，适合整站统一命名。

规则
github.com
实际 URL
https://github.com/acme/app/pulls
title 效果
GitHub 工作区

URL 正则：花括号捕获

{1} 表示一个路径段；名称中的 $1 会替换为捕获到的内容。

规则
https://linear.app/acme/issue/{1}
实际 URL
https://linear.app/acme/issue/ENG-42
title 效果
任务 ENG-42（名称填：任务 $1）

URL 正则：通配内容

使用正则 .* 匹配任意后续路径，适合整个栏目。

规则
https://docs.example.com/guides/.*
实际 URL
https://docs.example.com/guides/getting-started
title 效果
产品文档

URL 正则：圆括号捕获

圆括号可捕获更灵活的内容；使用 $1 写入名称。

规则
https://app.example.com/reports/(daily|weekly)
实际 URL
https://app.example.com/reports/weekly
title 效果
报告：weekly（名称填：报告：$1）
