# Onboarding 使用指南与演示方案

更新日期：2026-09-23  
状态：自动化验证完成，等待 Chrome 人工验收

## 约束

1. 竞品页面仅作为信息结构参考，不复制其文案、素材、联系方式或功能承诺。
2. 所有说明必须匹配本插件真实行为：页面、标签、永久规则三种生命周期；快捷键展示 Chrome 当前实际绑定。
3. “How to use / 使用步骤”是内容标题，不是按钮；切换语言不得删除其三个步骤节点。
4. 演示素材必须来自本插件 UI，展示打开弹框、修改名称、选择 Emoji、保存和恢复原值。
5. 中英文共用同一演示素材；图片必须有替代文本，并在 `prefers-reduced-motion` 下提供静态展示。
6. 不新增运行时网络请求和第三方依赖，素材随扩展本地打包。

## 实施项

| 项目 | 验收标准 |
| --- | --- |
| 修复使用步骤 | 三张步骤卡在英语和中文切换后始终存在，标题单独翻译 |
| 演示区域 | Onboarding 中出现本地操作演示，内容与当前 TAB_RENAME UI 一致 |
| 双语内容 | 演示标题、说明、替代文本均支持英语和简体中文 |
| 返回入口 | 扩展图标右键菜单提供“View welcome guide / 查看使用指南”，打开 Onboarding |
| 自动验证 | 覆盖步骤节点不丢失、菜单语言和点击行为、演示资源进入 `dist` |
| 人工验证 | Chrome 中切换语言、观看演示、从扩展图标右键重新打开指南 |

## 交付门槛

- `npm run typecheck`、完整测试、`npm run build` 全部通过。
- `dist/` 包含演示资源，Onboarding 不依赖外部 URL。
- 演示不宣传不存在的跨窗口恢复能力，也不硬编码一个可能未分配的快捷键。

- Vitest 共 11 个测试文件、74 个测试，全部通过。
- 生产构建通过，演示图标已复制到 `dist/onboarding/`。
