# Chrome Web Store listing copy (English)

**Name:** Tab Renamer - Free Tab Title Editor  
**Category:** Productivity  
**Short description:** Rename any browser tab instantly. Supports exact URL, URL pattern, and domain matching rules. Local-first, no data collected.

## Detailed description

Tab Renamer helps you organize a crowded browser by giving each tab a name you can recognize at a glance.

Press a keyboard shortcut or click the toolbar icon on any webpage to open an inline renaming interface. Choose the scope that fits your workflow:

• Page-only — the name disappears when you navigate away.
• Tab session — the name sticks through reloads and in-page navigation until you close the tab.
• Permanent rule — saved locally and reapplied every time a matching page opens.

Three professional matching modes let you create precise rules:

• Exact URL — targets a single page by its full address.
• URL pattern — uses {1} placeholders or regex capture groups to match dynamic URLs and insert captured values into the tab name.
• Domain — applies one name to every page under a hostname.

Rules follow a fixed priority (exact URL > URL pattern > domain), and page or tab-session names always override rules. The result is predictable and never flickers.

More features:
- Manage all rules in a dedicated options page: search, edit, enable, disable, delete, import, and export.
- Keyboard-first design: Enter to save, Esc to close, keyboard shortcut to open.
- Context menu entry for quick access.
- Data stays on your machine — no network requests, no telemetry, no uploads.
- Free and open source. No ads, no in-app purchases.

If you grant optional site access, permanent rules apply automatically after navigation. You can revoke that permission at any time.

Chrome-protected pages (chrome://, Web Store, new tab, other extension pages) cannot be modified. File URLs and PDFs depend on browser settings.

## Privacy fields

- **Single purpose:** Help users assign recognizable names to browser tabs using rules with flexible URL matching, stored locally in the browser.
- **User data:** No user data collected. Page titles, URLs, rules, and settings are processed and stored only in the browser.
- **Remote code:** No, this extension does not use remote code.
