# Chrome Web Store listing copy (English)

**Name:** Tab Rename  
**Category:** Productivity  
**Short description:** A local-first, predictable tab renaming tool

## Detailed description

Tab Rename turns a crowded browser into tabs you can recognize at a glance.

Open the full-page naming interface on any ordinary webpage with a keyboard shortcut or the toolbar icon. Name only the current page, keep a name for the current tab session, or create lasting rules for an exact URL or a domain. Page and tab-session names always take precedence, so the result stays predictable.

- Rename a tab directly on its page. Press Enter to save and Esc to close.
- Choose page-only, tab-session, or permanent-rule scope.
- Create, search, edit, pause, import, and export exact-URL and domain rules.
- Keep applicable names across dynamic page changes, reloads, and navigation.
- Local-first by design: no network requests, telemetry, or uploads of page titles, URLs, or settings.

If you explicitly grant site access, permanent rules can apply automatically after navigation and on already open matching pages. You can revoke that access at any time in browser extension settings.

Chrome-protected pages such as `chrome://`, the Chrome Web Store, new-tab pages, and other extension pages cannot be modified. File URLs and PDFs depend on browser settings and the viewer implementation.

## Privacy fields

- **Single purpose:** Help users assign recognizable names to browser tabs and save those names or matching rules in the user-selected scope.
- **User data:** No user data collected. Page titles, URLs, rules, and settings are processed and stored only in the browser.
- **Remote code:** No, this extension does not use remote code.
